# 🎬 JL Assistência especializda
## 📝 Descrição do Projeto
Este projeto consiste em um site para divulgar e entrar em contato com uma assistência
Desenvolvido como parte das disciplinas de **Desenvolvimento Front-End
Para Web (2026.2)**, ele é formado por 5 páginas: uma página inicial com o banner da empresa, uma com informações de contato, uma falando sobre a filosofia e historia da empresa, uma apresentando serviços que a empresa oferece e o portfólio com o feedback de clientes 
## 🚀 Tecnologias Utilizadas
* **Linguagem:** HTML5, CSS e JavaScript
* **Bibliotecas:** Bootstrap
* **Ferramentas:** VSCode
* **Modelo de IA:** Gemini
## 📊 Resultados e Aprendizados
O projeto alcançou resultados sólidos em ambiente de teste, demonstrando
a eficácia do modelo híbrido.
* **O modelo atingiu 92% de acurácia** nos testes de validação.
* **Redução de Ruído:** Aprendi a aplicar a ligação entre páginas HTML
* **Visualização de Clusters:** Implementei gráficos que mostram como o
sistema agrupa filmes por afinidade.
## 🧠 Declaração de Uso Ético da IA
Este projeto utilizou inteligência artificial ([Gemini]) estritamente como ferramenta de suporte
tecnológico para [refinar o CSS]. Todo o código gerado foi revisado,
testado e compreendido por mim, garantindo a minha responsabilidade
integral sobre a autoria final, integridade e funcionamento da
aplicação.
